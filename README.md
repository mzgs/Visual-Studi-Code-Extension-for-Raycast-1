# Visual-Studi-Code-Extension-for-Raycast-1

This is a Visual Studio Code extension for Raycast. It allows you to quickly open files and folders in Visual Studio Code directly from Raycast.

## Installation

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mzgs/Visual-Studi-Code-Extension-for-Raycast-1/refs/heads/main/install.sh)
```
